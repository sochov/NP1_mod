# ナンバー認識モデル（plate-v2）

[ナンバー](../../docs/plate-recognition.md)画面の認識プロセスが使う学習済みモデルです。`tools/build.ps1` / `tools/build.sh` が配布物に含め、導入時に本体の `/overlay/owner-apps/np1-control/plate/models/` へ置きます。

| ファイル | 内容 | SHA-256 |
| --- | --- | --- |
| `detector.tflite` | ナンバー検出器（int8、入力640×384のRGB、出力`[1,N,5]`） | `f3a24c66b9979f719e571d6240b3c4062665f10187010ba9bbf2e7f1aca4e211` |
| `ocr.tflite` | 読取り器（float32、入力96×192のグレー、地名・分類番号・ひらがな・一連番号の9ヘッド。reader-v6b） | `19798fe401df176bf92288590f54e24df94bcf9fcb4a1d4931e35b34477f3262` |
| `plate-model.json` | 検出の閾値・ROI、読取りのヘッドとラベル、項目ごとの閾値 | `00d199cade40243a0d96f3db4f2f98a008622177b7d40df71c759f98c865024b` |

## 構成

- **検出器**: MobileNetV2（torchvisionのImageNet学習済み重みから開始）＋FPN＋stride 8のヘッド。1920×1080の前方映像のうちROI `[320,240,1280,768]`（x, y, 幅, 高さ）を640×384に縮小して探します。
- **読取り器**: 日本のナンバーの固定配置を利用した多ヘッド分類器です。地名138種（Lipla-jp 0.4.1と同じ一覧）、分類番号3桁（数字とA C F H K L M P X Y）、ひらがな42種、一連番号4桁を、それぞれ「未読」を含めて分類します。地名・分類番号・ひらがなは確信度0.6未満なら空欄（未読）にし、条件に一致させません。

## 学習データ

| データ | 用途 | 公開 |
| --- | --- | --- |
| Open Images V7の「Vehicle registration plate」付き画像 8,157枚（画像はCC BY 2.0、注釈はCC BY 4.0） | 検出器 | 含めない |
| 合成した日本のナンバー（`tools/plate/train/plates.py`、ローカルのシステムフォントで描画） | 読取り器・検出器 | 含めない |
| 開発者が撮影したナンバー写真・ドラレコ映像（他人のナンバーと位置を含む） | 読取り器・検出器・評価 | 含めない |

plate-v2では、読取り器の学習に使うドラレコの実写を増やしました（教師ラベルを付けたフレームを約1,500枚から約7,500枚に、学習に使える切り出しを42件から440件に）。あわせて、動きのブレ（長く斜めのもの）と、横から見たナンバー（ヨー方向の遠近）の加工を加えました。検出器と設定は plate-v1b と同じです。

実写の正解ラベルは、[Lipla-jp](https://github.com/ikeboo/Lipla-jp)（MIT）をPC上で先生役として動かして付けました。Lipla-jpのモデルやコードは同梱していません。学習データ、量子化に使った画像、評価用の画像はこのリポジトリにもリリースにも含めません。

## 精度（学習に使っていない映像、目視で確認した正解）

評価には、NP1本体の録画（2026-11-13の走行、約1時間半）と、別機種2台のドラレコ映像（昼・夜、計約1時間半）を使いました。どれも学習には使っていません。各モデルが読んだ番号を時間ごとにまとめて目で確認し、正しい・誤り・判読できないに分けました（正しいと確認できた車は164台）。

| 項目 | plate-v1b | plate-v2 |
| --- | --- | --- |
| 1フレームの読み（信頼度0.7以上）の正答率 | 95.3%（誤り93件） | 97.4%（誤り48件） |
| 記録（2回検出で確定）の正答率と、正しく記録できた車 | 89.6%・74台 | 94.3%・71台 |
| 記録（2回検出＋信頼度0.7以上・写り幅45px以上なら1回で確定）の正答率と車 | 88.7%・113台 | 94.1%・115台 |

- plate-v2では、1フレームの誤読がほぼ半分になりました。このため、信頼度が高い読みは1回の検出で記録できます（本体の設定「1回で記録する信頼度」、初期値0.7）。
- 夜間に遠く・小さく写るナンバー（写り幅40px前後）は、高い信頼度で誤読することがあります。そのため、写り幅45px未満の読みは1回では記録しません。
- 教師（Lipla-jp）の読みは、夜間の黄色ナンバーなどで誤りがありました。このため、評価は教師ラベルとの一致ではなく、目視の正解で行っています。評価の手順は [ナンバー認識の評価方法](../../docs/plate-evaluation.md) にまとめています。

使い方と設計の概要は [ナンバー認識と発話](../../docs/plate-recognition.md) を参照してください。
