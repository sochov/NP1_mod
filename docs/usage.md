# 画面の使い方

## メニューと表示の切替

| 表示する端末 | メニュー |
| --- | --- |
| PC（既定） | 画面上部に、左右いっぱいに浮かぶメニューバー。幅に余裕があれば10画面をすべて並べます。幅が足りないときは、「設定」（純正設定・システム）、「ネットワーク」（4G・Wi-Fi / AP・Tailscale）、「ドラレコ」（ライブ・ドラレコ再生・走行履歴・ナンバー）の順に、まとまりごとに折りたたみます |
| PC（切替時） | 左側のサイドバー。10画面をすべて縦に並べます |
| スマートフォン（幅860px以下） | 上部に浮かぶタイトルバーと、下部の「ダッシュボード・ネットワーク・ドラレコ・設定」。ダッシュボード以外は、押すとその中の画面を選ぶメニューが開きます |

PCのメニューには、接続状態の右に3つのボタンが並びます。左から、メニュー位置の切替、ダッシュボードの概要／詳細の切替、状態の更新です。ダッシュボードの切替ボタンは、ほかの画面で押すとダッシュボードへ移動します。同じ切替は「システム › 設定・バックアップ › 表示設定」にもあります。スマートフォンでは、タイトルバーの右側に、ダッシュボードの概要／詳細の切替と状態の更新のボタンがあります。

ダッシュボードには2つの表示があります。

- **概要（既定）**: 現在地の地図を画面いっぱいの背景にし、その端に情報を配置します。
  - 左上: 走行の記録
  - 右上: 前方・車内のライブ映像
  - 下端: 同じ幅・同じ高さの4枚を、左から 4G データ通信、ネットワーク（Wi-Fi AP・Wi-Fi STA・Tailscale）、リソースモニター、本体の状態（稼働時間・Load average・SDカード・本体空き容量）の順に並べます

  ウィンドウの高さに合わせて、走行グラフとライブ映像の高さを調整します。

  幅がおよそ1280px未満のPCでは、上部に地図を見せ、その下を同じ幅の2列にします。走行の記録とライブ映像（前方・車内を横並び）を同じ高さで並べ、その下に4枚を2枚ずつ並べます（縦にスクロールします）。

  スマートフォンでは、地図が画面全体の背景になります。右上に前方カメラを小さく表示し（押すと「ライブ」を開きます）、そのほかの情報は下から引き出すパネルに入れています。パネルは上部のつまみを押すか、上下にドラッグして、小さく・半分・全面の3段階に切り替えます。内容をスクロールできるのは全面のときです。

  地図は現在地を中心に追従します。PCでは地図の上でマウスホイールを回すと、スマートフォンではピンチ操作で、現在地を中心に拡大・縮小できます（地図をドラッグして動かすことはできません）。緯度・経度（カンマ区切り）、衛星数、精度は、半透明で地図に重ねます。PCでは下段の4枚のすぐ上の左端（右端は地図の出典表示）、スマートフォンでは引き出しパネルのすぐ上の左端です。
- **詳細**: 概要で省いた項目も含めて、すべての情報を表示します。Wi-Fi APの動作、Wi-Fi STAの本日の通信量、Tailscaleのアカウントと通信経路、温度センサーごとの値などは詳細で確認できます。

メニュー位置とダッシュボードの表示は、操作しているブラウザーに保存します。本体には書き込まないため、PCとスマートフォンで別々に選べます。テーマ（ライト／ダーク）は従来どおり本体に保存します。

## ダッシュボードと走行履歴

以下は「詳細」表示の説明です。「概要」でも、走行の記録・ライブ映像・地図・4Gの操作は同じです。

ダッシュボードの「走行の記録」に距離と時間をまとめて表示します。期間は7・30・90・365日、全期間、カスタムから選び、日・週・月で集計できます。棒グラフは各期間の値、折れ線は累計です。

PCでは上段左に走行の記録、右に「GPS・録画」を配置します。4G・Wi-Fi AP・STA・Tailscaleは、その下の一列にまとめています。GPS・録画の上部には録画状態と保存済み件数を並べ、その下に前方・車内のJPEGライブ映像をカードの左右いっぱいに表示します。ライブ映像は約2秒に1回更新し、停止ボタン、画面外へのスクロール、別タブへの移動で取得を止めます。

地図はカードの横幅いっぱいに表示し、緯度・経度・衛星数・精度を地図上に重ねます。現在地と地図は、純正の画像認識が毎秒更新する位置を2秒ごとに取得して追従します。この位置を現在地として扱うのは、直近10分以内にGPSの測位記録があるか、位置が実際に動いているときだけです。衛星数と精度は、録画のクリップが閉じるたび（約3分ごと）に書かれるGPSの記録から取り、20秒より古い場合は「（2分前）」のように経過時間を添えます。測位できていないときは「測位できていません」と表示し、純正が把握している最後の位置を灰色の印（最後に分かっている位置）で示します。地図には過去24時間の走行経路を重ねます。録画中の判定はSD上の録画ファイルの更新から行い、停止から表示が変わるまで最大約25秒かかる場合があります。初回の更新確認中やSDの取得不能は、録画停止と区別して表示します。

下段左のリソースモニターでは4G・Wi-Fiを横並びにし、それぞれの上下速度、CPU・RAM・温度の現在値と推移を確認できます。温度はCPU・GPU・モデム・eMMCを色分けして重ねます。表示期間は5・15・60分です。推移はこの画面を開いている間の観測を使い、取得できなかった区間を0で埋めません。SDカードと本体容量は右側の「本体の状態」に残し、ラベルの横に残容量／全容量を表示します。稼働時間の下にはLoad average（1分・5分・15分）の現在値を表示します。モバイルでは各セクションを縦に並べます。

走行履歴では日別・走行別の詳細、GPSの経路、電波品質を確認できます。「録画と地図」から、その走行の時刻をドラレコ再生で開けます。未測位や測位が途切れた区間には経路を補いません。距離の取得不能を0kmとは表示しません。

## ドラレコ再生

1. カレンダーで録画のある日を選びます。
2. 時間バーの色が付いた区間をクリック・タップします。24時間・6時間・1時間・15分へ拡大でき、時刻の直接入力も可能です。
3. 前方・車内・並べて表示を切り替えます。並べて表示中の音声は主となるカメラから再生します。
4. タイムラインの下にある地図が再生時刻に追従します。経路や走行区間を選ぶと、その時刻に対応する録画へ移動します。

録画も測位もある区間だけが連動します。時刻付近の位置記録がなければ、地図に現在位置の印を出しません。位置が記録されていない日も映像は再生できます。録画は原本H.264 / AACを使い、確定待ちのファイルは確定後に時間バーへ追加します。

## ライブ

ライブ画面で表示を開始します。H.264は純正サービスがSDへ書き込む映像を読み取るため、SD未挿入・録画停止中には取得できません。前方・車内・並べて表示はドラレコ再生と共通です。JPEGプレビューも利用できます。ダッシュボードの「ライブ」の横のリンクからライブ画面へ、「録画中・件数」の横のリンクからドラレコ再生へ移動できます。

ライブのマイク音声には対応していません。保存済み録画の音声や、ブラウザーから本体へ送る共有音声とは別の機能です。

## ナンバー

前方カメラの映像から読み取ったナンバーを、場所と一緒に「記録」タブの一覧と地図へ表示します。一覧と地図の点は連動し、条件に合ったナンバーはオレンジで強調します。各記録の「録画を再生」で、検出した時刻の前方カメラの録画を画面上の小窓で再生します（最初に読んだ10秒前から、最後に読んだ10秒後まで）。小窓の「ドラレコ再生で開く」から、同じ時刻のドラレコ再生画面へ移れます。「条件と設定」で記録の有効化、保存日数・画像容量、条件（地名・分類番号・ひらがな・番号、`*`は任意の1文字）、読み上げのメッセージ（文字または音声ファイル）と声・音量を設定します。読み上げにはシステム › LED / 音声でVOICEVOX APIのキーを設定してください。詳細は [ナンバー認識と発話](plate-recognition.md) を参照してください。

前面LEDの「点灯」「消灯」は一時テストです。既定は5秒で自動消灯し、10秒・30秒も選べます。通常のプリセットは変更しません。常時点灯は「点灯し続ける」を明示的に選んだ場合だけ保存します。

## 4G・Wi-Fi・Tailscale

システム › 設定・バックアップの「本体の自動更新」に、更新を防ぐ各仕組み（取得の停止・削除防止・自動復旧・通信遮断・監視）の状態と警告を表示します。取得済みの更新データやSDカードの更新用ファイルが見つかった場合は、本体を再起動する前に確認してください。更新を許可する操作には確認があります（非推奨）。

4G画面は、回線の状態、通信量・月間上限、APN接続設定の順に並びます。キャリア、接続バンド、電波品質、通信量を確認します。通信量は本システムが記録した値で、Wi-Fiと4Gを分けて集計します。4Gの残量は設定した上限から記録分を引いた目安で、通信会社の請求データではありません。APNはプロファイルの編集・保存まで対応し、モデムへの実適用は未対応です。

Wi-Fi / AP画面の先頭の「インターネット回線」で、本体・純正アプリ・ホットスポットにつないだ端末が使う回線を選びます。「自動」は、Wi-Fiが3分間つながらないと4Gへ切り替え、4Gの間も3分ごとに40秒だけWi-Fiを試して、保存済みのWi-Fiに戻れたらWi-Fiへ戻します。「Wi-Fi」「4G」はその回線に固定します。純正サービスはWi-Fi接続（STA）がオンの間は4Gを使わないため、4Gへの切替は純正のSTAをオフにして行います。

Wi-Fi / AP画面にはSTAの接続先、ホットスポットのSSID・認証・DHCP、接続端末もまとめています。ホットスポットにつないだ端末からは、この画面を http://192.168.226.1 で開けます。Tailscaleのアドレスや名前（`*.ts.net`）は、NP1がインターネットにつながっているときだけ使えます。

Tailscale画面ではアカウント・機器名・アドレス・接続状態を確認できます。機器名の変更もここで行います。管理画面はTailscaleのIPアドレスに加え、機器名（`<機器名>.<tailnet>.ts.net` と短い機器名）でも開けます。

## 純正設定・システム

MANAGE内の「純正設定」に、Alexa、運転サポート、ナビ・交通情報、案内・コエ、プライバシー、車両・取付をまとめています。Alexaは画面の先頭に表示します。取得できる値と変更できる項目は、ファームウェアと追加ヘルパーの有無で異なります。

システムには本体情報、ルーティング、SD、LED / 音声、USB、ログ、録画バックアップ、表示設定をまとめています。純正サービスの個別操作では、依存関係のために停止できない組み合わせがあります。SDはFIFO録画を前提とし、空き容量だけで警告しません。

LED / 音声の「音声合成（VOICEVOX API）」では、ナンバーの読み上げに使うAPIのエンドポイントとキーを設定します。キーは保存後に表示しません。

LED / 音声の画面連動機能では、ブラウザーの画面共有から表示対象を選び、横方向の範囲の平均色を5つのLEDへ送ります。彩度・明るさ・コントラストを調整できます。音声共有に対応するブラウザーと共有対象では、本体への音声転送も選べます。画面共有にはHTTPS等のブラウザー側の利用条件があり、HTTP接続では利用できない場合があります。

## 設定のバックアップ

システム › 設定・バックアップの「バックアップ」で、画面で設定した内容を1つのファイルに書き出し、復元できます。対象は、表示設定（テーマ・お気に入り・4Gの月間上限）、前面LED、ナンバー認識の条件と読み上げ（読み上げ用にアップロードした音声を含む）、VOICEVOXの接続先とAPIキー、録画のNASバックアップの接続先と対象、ホットスポット（SSID・パスワード・優先回線・自動起動）、NCCで追加したWi-Fi、APN、インターネット回線の切替、書き出したブラウザーの表示設定（メニュー位置・ダッシュボードの表示）です。ファイルにはパスワードやAPIキーが含まれるため、安全な場所に保管してください。

復元では、ファイルを選ぶと復元される項目の一覧を表示し、確認してから適用します。変更のあった項目だけを書き換え、関係するサービスを再起動します（30秒ほど画面がつながらないことがあります）。APNは保存のみで、本体への適用はAPN画面で行います。純正側に保存されたWi-Fiはパスワードを読み出せないため名前だけを記録し、復元しません。本体の自動更新の設定も記録のみで、復元しても有効には戻しません。以前の形式（表示設定のみ）のファイルも復元できます。

## 録画のNASバックアップ

システムの「録画バックアップ」で設定します。

- 常時録画と緊急録画は個別にON / OFFを設定します。
- 経路はWi-Fi STAまたはTailscaleを選び、それぞれにSMB・SFTP・WebDAVの接続方式と保存先を保持できます。
- 自動実行のタイミングはリアルタイム、または指定SSIDへの接続から選びます。
- 進捗の確認と中断・再開ができます。原本やNASの既存ファイルは削除せず、確定済みファイルを上書きしません。

初期状態では自動バックアップはOFFです。SDのFIFOで転送元が更新されると、そのファイルの転送を停止する場合があります。切断や本体再起動を含む復旧の通し検証は未完了です。
