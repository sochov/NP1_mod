# 変更履歴

## 0.6.1 — 2026-11-27

- ナンバーの読み上げを、分類番号・一連番号とも1桁ずつ、0は「まる」と読む方式に変更しました（例: 「相模503 あ12-34」→「さがみ ご まる さん あ いち に さん よん」）。
- VOICEVOXで事前に保存する部品を、全地名138・数字0〜9・分類番号の英字・ひらがな46文字に揃えました。使わなくなった2桁の部品は次回保存時に削除されます。
- デバッグ用に「検出したナンバーをすべて読み上げる」設定を追加しました。保存済みの部品音声だけを使い、ナンバーはAPIへ送りません。
- 高度化PICSで、実道路の疎な受信（同一交差点で2.5〜9秒間隔）でも赤→青を発話するよう判定を10秒に広げました。ナンバーの読み上げ中は信号の発話がスピーカーの空きを待ちます。再生の一時失敗の再試行、音声欠損時の再準備、発話処理停止時のsystemdウォッチドッグによる自動再起動、発話判定の永続ログを追加しました。

## 0.5.1 — 2026-11-23

- 指定したSSIDへの接続後にIPアドレスが取得できない問題を修正。非公開SSIDの探索と、直近に確定したNCC管理プロファイルの再接続を改善しました。
- 自動切替は実際のWi-FiのDNS・HTTPS疎通を確認し、電波が届いていても通信できない場合は4Gに戻ります。純正のWi-Fi応答と保存設定が食い違って4Gへ戻れない既知の状態も、条件を照合して復旧します。
- この版はWi-Fi切替サービス、ヘルパー、DHCP用スクリプトも更新します。既存環境には `tools/deploy-uplink-update.py` を使用し、バイナリだけの自動更新は配布しません。

## 0.5.0 — 2026-11-22

- システムの設定に「NP1 Control Center の更新」を追加。新バージョンの即時更新、ダウンロードして次回起動時に適用、更新確認のみ、自動更新を無効化の4モードに対応。手動での即時更新とWi-Fiのみ／4Gも許可の回線設定を用意。
- GitHub Releaseの署名とNP1向けバイナリを検証し、適用後の確認に失敗した場合や切り替え中に電源が落ちた場合に旧版へ復旧。純正OTA設定は「純正ソフトウェアの更新抑止」と表示。
- 0.5.0から更新サービスを初回導入できます。導入手順と更新対象の条件は [NP1CCの自動更新](np1cc-auto-update.md) を参照してください。

## 0.4.0 — 2026-11-16

- 地図をMapLibreのベクトルタイルへ移行。画面ごとにテーマを選択でき、カラフルな配色も用意。
- ナイト地図の道路・建物・文字を控えめな配色へ調整し、走行軌跡を見やすく変更。READMEの画面例は東京駅周辺の道路に沿うサンプル経路と、1段階引いた地図へ更新。
- ダッシュボードの走行経路を過去24時間で表示し、取得済みの細かいGPSを保持。走行集計は7日を既定にし、現在地ボタン・グラフ・中幅のパネル配置を調整。ナンバー一覧には日付の区切りを追加。
- 純正設定のAlexa下に本体操作のグリッドを追加。SDフォーマット、録画・車両設定、取付調整、GNSS、診断、ナビ、認証、純正Wi-Fi等の固定操作を提供。非対応・制限は理由を表示し、要求の受付と完了を区別。

- ナンバーの読取り器を更新（plate-v2）。ドラレコの実写での学習を増やし、1フレームの誤読をほぼ半分に削減。信頼度0.7以上で写り幅45px以上の読みは1回の検出で記録するようにし、すれ違う車など一瞬しか写らない車も記録可能に（設定「1回で記録する信頼度」、1で無効）。NP1本体の録画を含む3種の映像で、記録の正答率94%を保ったまま、記録できる車を約1.6倍に。
- ナンバー認識の稼働状況（検出側の状態・処理速度・受け取り状況）を1分ごとに本体へ記録し、7日分を保持。
- 管理画面の通信を圧縮し、画面本体のファイルをブラウザーにキャッシュさせるよう変更。4G経由での表示が軽くなり、10秒ごとの状態取得の通信量は約10分の1に。
- 本体のファームウェア更新の防止を多層化。停止フラグに変更不可属性を付けて削除を防ぎ、見張り役が30秒ごとに確認して消えたフラグを作り直す。純正の更新処理の専用アカウントだけ外部通信を遮断。取得済みの更新データ・提供中の更新・SDカードの更新用ファイル・更新処理の変化を監視して画面に警告。更新を許可する操作に確認を追加。
- ナンバーの記録一覧に「録画を再生」を追加。検出時刻の前後だけを前方カメラの録画から小窓で再生し、そこからドラレコ再生画面へ移動可能。
- 4G画面の「通信量・月間上限」を折りたたまずに表示し、APN接続設定の上へ移動。
- Wi-Fiの圏外で4Gへ切り替わらない問題を修正。Wi-Fi / AP画面の「インターネット回線」で「自動・Wi-Fi・4G」を選択可能。自動ではWi-Fiが3分つながらないと4Gへ切り替え、3分ごとにWi-Fiを試して戻る。ホットスポットにつないだ端末も4G経由で通信可能。
- ナンバーを検出しても記録されない問題を修正。検出側が番号を1から振り直したときに、受け取り位置を合わせ直す。
- ダッシュボードの現在地を、純正が毎秒更新する位置で2秒ごとに表示。衛星数・精度はGPSの記録の経過時間付きで表示し、測位できていないときは最後に分かっている位置を灰色で表示。過去24時間の走行経路を地図に表示。
- Tailscaleの機器名（`*.ts.net` と短い名前）で管理画面を開けるよう修正。
- 設定のバックアップを全項目に拡大。前面LED、ナンバー認識の条件と読み上げ、VOICEVOX、NAS、ホットスポット、NCCで追加したWi-Fi、APN、回線切替、ブラウザーの表示設定を、パスワード・APIキーを含めて保存・復元。
- ホットスポットにつないだ端末から管理画面が開けなくなる問題への対策。Webサービスが他のサービスの失敗に巻き込まれて止まらないようにし、各サービスが再起動をあきらめないよう変更。待ち受けが止まった場合は自動で作り直す。ホットスポットからの開き方（http://192.168.226.1）を画面に表示。
- 録画が上書きされて消えたクリップの再生・ダウンロードを「見つからない」として扱うよう修正。

## 0.3.0 — 2026-11-13

- 画面全体のデザインを刷新。配色・角丸・影・入力欄・ボタンを統一し、9〜10pxだった小さな文字を11px以上に拡大。
- PCのメニューを、画面上部に左右いっぱいに浮かぶメニューバーへ変更（既定）。幅に余裕があれば全画面を並べ、足りないときはまとまりごとに折りたたむ。左側のサイドバーにも切り替え可能。
- スマートフォンのメニューを、上部に浮かぶタイトルバーと、下部の「ダッシュボード・ネットワーク・ドラレコ・設定」へ変更。各項目から、その中の画面を選ぶメニューを表示。
- ダッシュボードに、現在地の地図を画面いっぱいの背景にして、端に要点を配置する「概要」表示を追加し、既定に設定。従来のすべての情報を並べた表示は「詳細」として選択可能。メニュー（スマートフォンではタイトルバー）のボタンで切り替え。
- 概要のスマートフォン表示は、右上に前方カメラ、下から引き出すパネルにそのほかの情報を配置。
- 概要の地図を、PCではマウスホイール、スマートフォンではピンチ操作で拡大・縮小可能に変更。
- 走行の記録から「集約」のラベルを省略。スマートフォン幅では期間を「7日・30日・365日・全期間・カスタム」に絞り、集約の選択と1行に配置。
- メニュー位置とダッシュボードの表示は、ブラウザーごとに保存。
- システムの区分タブを、スマートフォンでは横スクロールの1行に変更。
- 純正設定のON／OFFをスイッチ表示へ変更。前面LEDの設定欄を2列に整理。
- 全画面のUI検証で、一時的なカメラプレビューの開始・終了を設定変更と誤判定しないよう修正。設定への書き込みは引き続き検証で拒否。

## 0.2.1 — 2026-11-12

- モデルの権利表示を読取り器・設定と検出器で分離。検出器の初期重みの配布元・ハッシュを明記し、権利表示を配布物へ同梱。
- ダッシュボードの4G欄を、キャリア・バンド・電波強度、今月／本日の通信量、右側の残量リングへ簡素化。詳細画面と月間上限の編集を維持。
- 電波ピクトをキャリア名の左へ移動。Wi-Fi STAは認証の表示を省き、SSIDの横にチャンネルと周波数を表示。
- 地図配信に必要なRefererを送るよう修正。測位点のない地図はタイルを取得せず、ナンバーの地図操作・ポップアップもライト／ダークに追従。
- ナンバー読み上げで選択した声が反映されない不具合を修正。話者IDをAPI仕様に合わせて送り、誤った声のキャッシュを使わず再生成。
- ナンバーの条件ごとにLED通知を追加。単色（点灯・ゆっくり点滅・流れる光）／レインボー、色・明るさを選択可能。発話中と終了後2秒間光らせ、本体での試聴にも反映。通知後は消灯し、保存済みプリセットは保持。
- 前面LEDは「点灯」「消灯」で一時テストする操作を既定とし、5／10／30秒で自動消灯。常時点灯は明示的に選択した場合のみ保存。
- 未完了のホットスポット優先回線切替を画面から非表示化。

## 0.2.0 — 2026-11-12

- ダッシュボードの通信・録画・リソース表示を整理し、カード見出しと容量表示をコンパクトに統一。
- 録画のタイムラインと走行地図を連動し、地図をタイムラインの下へ配置。
- ナンバー画面で条件が未登録の場合に設定タブが消える不具合を修正。
- アプリのバージョンを画面と配布物の依存関係一覧に記録。
- ライブ表示と録画再生の操作を分け、左メニューの「カメラ」を「ライブ」へ変更。
- CPU・RAMの通常の計測間隔でグラフが途切れる表示を修正し、温度はCPU・GPU・モデム・eMMCを重ねて表示。
- LED／音声画面の見出しと間隔を揃え、VOICEVOX API設定を末尾へ移動。
- Alexaを純正設定の先頭へ統合。NP1 SERVICEカテゴリを廃止し、純正設定をMANAGEのシステム直上へ移動。
- システムの純正サービスをカードグリッドで表示。
- 複数のブラウザーがライブ画像を同時取得したときの競合を、JPEG変換の順番待ちで解消。
