# 変更履歴

## 未リリース

- 画面全体のデザインを刷新。配色・角丸・影・入力欄・ボタンを統一し、9〜10pxだった小さな文字を11px以上に拡大。
- PCのメニューを、画面上部に左右いっぱいに浮かぶメニューバーへ変更（既定）。幅に余裕があれば全画面を並べ、足りないときはまとまりごとに折りたたむ。左側のサイドバーにも切り替え可能。
- スマートフォンのメニューを、上部に浮かぶタイトルバーと、下部の「ダッシュボード・ネットワーク・ドラレコ・設定」へ変更。各項目から、その中の画面を選ぶメニューを表示。
- ダッシュボードに、現在地の地図を画面いっぱいの背景にして、端に要点を配置する「概要」表示を追加し、既定に設定。従来のすべての情報を並べた表示は「詳細」として選択可能。メニュー（スマートフォンではタイトルバー）のボタンで切り替え。
- 概要のスマートフォン表示は、右上に前方カメラ、下から引き出すパネルにそのほかの情報を配置。
- 概要の地図を、PCではマウスホイール、スマートフォンではピンチ操作で拡大・縮小可能に変更。
- 走行の記録から「集約」のラベルを省略。スマートフォン幅では期間を「7日・30日・365日・全期間・カスタム」に絞り、集約の選択と1行に配置。
- メニュー位置とダッシュボードの表示は、ブラウザーごとに保存。
- システムの区分タブを、スマートフォンでは横スクロールの1行に変更。
- 純正設定のON／OFFをスイッチ表示へ変更。前面LEDの設定欄を2列に整理。

## 0.2.1 — 2026-11-12

- モデルの権利表示を読取り器・設定と検出器で分離。検出器の再配布条件が確認未了であることと、初期重みの配布元・ハッシュを明記し、権利表示を配布物へ同梱。
- ダッシュボードの4G欄を、キャリア・バンド・電波強度、今月／本日の通信量、右側の残量リングへ簡素化。詳細画面と月間上限の編集を維持。
- 電波ピクトをキャリア名の左へ移動。Wi-Fi STAは認証の表示を省き、SSIDの横にチャンネルと周波数を表示。
- 地図配信に必要なRefererを送るよう修正。測位点のない地図はタイルを取得せず、ナンバーの地図操作・ポップアップもライト／ダークに追従。
- ナンバー読み上げで選択した声が反映されない不具合を修正。話者IDをAPI仕様に合わせて送り、誤った声のキャッシュを使わず再生成。
- ナンバーの条件ごとにLED通知を追加。単色（点灯・ゆっくり点滅・流れる光）／レインボー、色・明るさを選択可能。発話中と終了後2秒間光らせ、本体での試聴にも反映。通知後は消灯し、保存済みプリセットは保持。
- 前面LEDは「点灯」「消灯」で一時テストする操作を既定とし、5／10／30秒で自動消灯。常時点灯は明示的に選択した場合のみ保存。
- 未完了のホットスポット優先回線切替を画面から非表示化。

## 0.2.0 — 2026-11-12

- ダッシュボードの通信・録画・リソース表示を整理し、カード見出しと容量表示をコンパクトに統一。
- 録画のタイムラインと走行地図を連動し、地図をタイムラインの下へ配置。
- ナンバー画面で条件が未登録の場合に設定タブが消える不具合を修正。
- アプリのバージョンを画面と配布物の依存関係一覧に記録。
- ライブ表示と録画再生の操作を分け、左メニューの「カメラ」を「ライブ」へ変更。
- CPU・RAMの通常の計測間隔でグラフが途切れる表示を修正し、温度はCPU・GPU・モデム・eMMCを重ねて表示。
- LED／音声画面の見出しと間隔を揃え、VOICEVOX API設定を末尾へ移動。
- Alexaを純正設定の先頭へ統合。NP1 SERVICEカテゴリを廃止し、純正設定をMANAGEのシステム直上へ移動。
- システムの純正サービスをカードグリッドで表示。
- 複数のブラウザーがライブ画像を同時取得したときの競合を、JPEG変換の順番待ちで解消。
