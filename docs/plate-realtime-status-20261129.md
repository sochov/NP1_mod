# ナンバー認識リアルタイムステータス

ナンバー画面の「リアルタイム」タブは、認識処理の負荷と滞留を端末内の集計値だけで確認する。前方画像やナンバー文字列を監視APIへ追加送信せず、既存のUnix socket経由ステータスを2秒間隔で取得する。

## 表示値

- 検出処理速度: 直近10秒のフレーム開始時刻から算出した実測fpsと設定上の目標fps。
- OCRキュー: 現在の待機件数と設定容量。既定は2件、設定可能範囲は1～4件。
- OCR完了速度: 画面を開いてから最大2分間に増えた完了件数を経過秒で割った値。
- キュー破棄率: `破棄 / (完了 + 破棄)`。キューで古くなった画像を破棄して最新画像を優先した割合。
- OCR抑制率: `抑制 / (完了 + 破棄 + 抑制)`。同じ車両の類似品質画像や、全項目確定後の不要な再OCRを投入しなかった割合。異常や認識失敗ではない。
- フレーム鮮度: 最後に処理した前方フレームからの経過時間。
- FPSとOCRキューの直近2分グラフ、認識エンジン、入力元、collector、保存量。

累計カウンターは認識プロセスのセッション単位であり、プロセス再起動時に0へ戻る。画面はセッションIDの変化を検出すると直近推移をリセットする。ブラウザーが非表示の間はポーリングを止め、端末とネットワークの負荷を増やさない。

## ログ

既存の1分間隔health journalへ、実測fpsに加えて目標fpsとOCRキュー容量を記録する。通常運用のログ量はほぼ変わらず、後からキュー滞留・破棄と設定値の関係を確認できる。
