# 追加UI・カメラ指示

2026-11-11の追加指示を優先する。

- 緑基調を廃止し、白/グレーと中立的なダーク配色。操作アクセントは青、状態の良否だけ色を残す。
- サイドメニューを14px・太字にし、左上ブランドと右上Ownerアイコンを削除。
- カメラは表示ボタンから直接開始し、許可modalは出さない。短期セッションは内部で自動管理、閲覧中は更新、無閲覧30秒で失効。
- 既存NV12 exportと純正MP4を比較し、NV12順序が一致すること、純正録画にも同じ色かぶりがあることを確認。
- JPEG変換をvideo-range BT.601に修正。プレビュー限定の控えめなハイライト白色補正を追加し、「自動補正/元映像」で切替可能。元映像・SD録画は変更しない。
- 取得した純正MP4二系統にH.264 1920x1080とAAC 48kHz stereoがあることをffprobeで確認。
- 最終化済みMP4は`ftyp/free/mdat/moov`で、moovは末尾。書込み中のmdatをそのままブラウザーへ流すだけではライブ化できない。
- H.264ライブ/音声はQMMF/圧縮buffer/PulseAudioの共存経路を調査する。新規QMMF camera sessionやraw ALSA排他openはしない。
- LED参照材料とradio-map参照材料はresources/referencesへ未改変コピーして保持。元のtmp配下も削除しない。
