# 公開前の対象確認

2026-11-12、指定されたGitHubリポジトリへの初回pushに先立ち、mainの現在のファイルと到達可能な全コミット・全blobを確認した。別作業のナンバープレート認識ブランチやローカルのstashはpush対象に含めない。

- `docs_private`、ローカル開発ガイド、`tmp`、取得資料、実機バイナリ、録画、資格情報は履歴を含めて対象外。
- 私有値リストとの照合、一般的な秘密鍵・API tokenパターン、バイナリ形式・拡張子の検査では対象の混入を検出しなかった。リストや生の検査結果はignored tmpに保存し、値を公開しない。
- 純正連携コードは独自の実装と互換性のための調査結果。純正ソース、SDKヘッダー、逆コンパイルしたソース、ファームウェアやライブラリは含めない。実行時は端末の既存ファイルを利用する。
- ライセンス未提示のLED参考サンプル自体は含めず、sysfsの互換性情報をもとにGo側で制御する。radio-mapはMITの設計参考資料として帰属表示を保持。
- npmの全固定依存、Goモジュールグラフと標準ライブラリ、任意のPython SSHホストツール、参考資料・外部Tailscale取得について、上流のライセンス・追加のNOTICEを [サードパーティライセンス](../THIRD_PARTY_LICENSES.md) に整理した。

ライセンス検査をCI・配布ビルドへ組み込み、依存更新と一覧の不一致や原文改変を検出する。公開するのはソースと文書であり、ビルド済み実機配備物・参考資料のアーカイブはこのpushに含めない。
